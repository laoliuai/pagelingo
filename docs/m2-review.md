## 审查未判断部分的决定

1. 语义质量与跨站泛化：本轮只以真实 12 块样本验证 API 和结构闭环；三类真实站点的人工质量评测保留在 M3。代价：M2 不保证不同文章的术语与语义质量。
2. 原生 Chrome / Edge：自动化验证生产扩展在 Chromium 中运行，另验证原样 ZIP；原生工具栏、授权弹窗和 Edge 由用户安装验收。代价：尚不能声称这些交互已人工通过。
3. Token 估算：继续使用通用预算估算，展示服务返回的 usage。代价：预算估算不等于具体模型 tokenizer 或账单。
4. 服务端计费：取消、网络中断或崩溃后的重试只保证客户端次数有限。代价：请求是否已生成/计费无法由客户端做到恰好一次，可能产生额外费用。
5. 密钥审查：独立审查不读取 `.env.local`；实际联调与打包脚本在内存中对比本地 Key，不输出它。代价：依赖配置和扫描路径正确，不能声称独立审查者再次读取了凭据。
6. 完整验证：独立审查不重复执行会写构建资源的全套检查；实现者完成修复后执行新的 `npm run check` 与 ZIP 校验。代价：全量运行证据来自实现者，边界复现与代码判断来自独立审查。
