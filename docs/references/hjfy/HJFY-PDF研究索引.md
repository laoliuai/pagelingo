## 停止标准

本轮已完成主要可借鉴设计与细节的静态提炼，并留下明确缺口。不继续无边界反编译或把周边函数拼成“完整还原”。你的优先实现路线是：

**来源/坐标 → 行与阅读图 → 可替换布局/OCR → 公式成员保护 → 表格事务 → 可信HTML。**
