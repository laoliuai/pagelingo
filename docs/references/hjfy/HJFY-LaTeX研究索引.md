# HJFY LaTeX 研究索引

仓库保存设计笔记；以下证据 JSON 与边界用例仅保留在本地 `temp/HJFY-parsed/`，不纳入 Git。这些静态分析不代表 PageLingo 已实现或验证了对应功能。

## 最终用途

为自有 LaTeX -> 中间格式 -> HTML 提取可借鉴规则和设计，PDF 保留前期结构分析资料。当前达到主要设计模块可参考的交付范围，不宣称恢复全部源码、完整 TeX 执行或原版运行效果。

## 推荐顺序

1. `LaTeX解析设计参考手册.md`：完整设计、具体细节、证据地址与不能照搬的规则。
2. `LaTeX核心流程参考伪代码.md`：定义分类、宏展开、环境与条件、受限区域、恢复及独立解析器流程。
3. `LaTeX解析边界用例.json`：42 个独立输入与验收性质，可接入自有测试框架；尚未在目标应用或自有解析器上执行。
4. `HJFY-0.1.5-LaTeX-deep-evidence.json`：本轮 74 条分析记录、73 个唯一地址，含一条受限环境反编译失败及同地址汇编补证。数字包含辅助函数，不等于73个已完整恢复的解析算法。
5. `HJFY-0.1.5-LaTeX-rules-evidence.json`：原二进制三组261/58/91项分类表及上一轮16函数结果。
6. `HJFY-0.1.5-static-evidence.json` 与 `HJFY-0.1.5-逆向初步报告.md`：初期占位、翻译、验证链。
7. `HJFY-0.1.5-LaTeX与PDF架构分析.md`、`HJFY-0.1.5-PDF-architecture-evidence.json`：PDF布局/OCR/对象保护和两类引擎宏观分工。

## 最值得借鉴

- 无损词法和原始区间，识别代码、数学、注释及条件区域。
- 宏签名与参数角色分离；别名继承引用与保护属性。
- 受限零参数文本宏展开，避免假装执行完整 TeX。
- 图注、脚注、边注、标题独立提取，不把所有章节类命令映射成 heading。
- 表格/图形环境保守保留并局部提取说明文字。
- 数学、引用、路径与资源数据不可变；外部文本处理通过映射保护。
- 未闭合和不支持的内容可恢复、可追踪，不静默丢文。
- 解析、翻译校验、HTML渲染三层分别处理安全与失败。

## 原实现边界

尚未证明完整 xparse、参数宏替换、catcode、TeX作用域、包执行、所有表格结构语义、条件求值或任意编码支持。它的恢复与长度/语言启发式不应直接成为自有解析器规范。

目录隔离、符号链接、循环防护等原程序安全策略未完整核实；手册相关条目是自有实现建议。

静态反编译仍有类型传播、相邻函数污染和跳转表警告。受限环境通过有效汇编及原跳转表恢复关键分类；表数据不按机器指令解释。原函数符号用于纠正临时别名。
