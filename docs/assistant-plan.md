# 阅读助手实施计划

日期：2026-10-06。用户已授权实施 [assistant-spec.md](assistant-spec.md)。

实施状态：步骤 1–6 已完成。2026-10-07 更新至插件 0.4.2、共享助手 SDK 0.2.0，修复选区请求组织、回车发送和侧栏标签页绑定。验证记录见 [assistant-validation.md](assistant-validation.md)。

1. 新建纯数据 assistant-core；落实文档、引用、消息 schema、身份、上下文预算和摘要协议。验证 Pi 固定版本的实际 API。
2. 接入无工具的 Pi runtime 与兼容模型调用；验证流式事件、取消、超时、普通响应、摘要和重试，提供仓库外 SDK 消费测试。
3. 添加网页正文 / 代码提取和选区映射；受信任后台提供入口、一次性选区投递、原文定位，不向网页暴露设置。
4. 添加独立对话数据库、容量 / 数量清理、草稿、并发锁和中断恢复。
5. 实现 React 侧栏、引用卡片、聊天、历史、Markdown、上下文范围和设置；加入右键与现有面板入口。
6. 补充端到端验证，检查翻译回归、包边界、原生插件加载、密钥与产物；编写使用说明并发布本地 ZIP。
