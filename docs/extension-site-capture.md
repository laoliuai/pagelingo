# 扩展收藏到私有资料站

站点保存原文、资源与可读版本；扩展已有的网页翻译设置和站点 BYOK 配置彼此独立。网页保存不依赖模型 Key。来源范围、保存结果、翻译进度分别显示，不把“已排队”当成“原文已保存”。

## 配对与权限

1. 按[安装说明](learning-site-install.md)启动 API、数据库和独立 worker，在站点登录自己的账号。
2. 在站点设置的设备区域生成一次性配对码。配对码有效期为五分钟，只能消费一次。
3. 打开扩展选项中的“资料站点”，填写站点 origin（HTTPS；本机可用 HTTP localhost/127.0.0.1）与配对码，点击“授权并连接站点”。只输入协议、主机、端口，不输入路径或账号密码。
4. 确认连接显示自己的用户名。设备 token 有效期为 30 天，限制在收藏、收藏状态、链接保存及非敏感偏好读取；它不能读取资料库、Reader、原件、模型 Key 或管理接口。

浏览器对站点和资源的授权按 origin 处理；Chrome 的授权不区分端口，实际请求仍固定到保存的站点 origin。跨域资源会单独提示。拒绝资源授权可以继续保存正文，结果明确显示“部分资源缺失”。网页脚本不能选择上传目标或发起通用资源请求；设备上传不携带站点 Cookie。

## 保存原文与阅读

在已加载的文章、X 主帖、知乎独立回答或公众号文章上点击扩展“保存到资料站”。X 只保存请求的主帖，不把回复或引用帖子混入正文；知乎问题页存在多个回答时需打开独立回答链接。未展开、未加载、登录墙及无法采集的内容不会自动补全；无法确定正文时保存链接并提示。

扩展克隆已确认的原文，不把注入译文或表单、Cookie、应用隐藏状态作为原文。图片以实际字节保存并校验，代码和受保护的公式保持结构。脚本、表单和不安全样式被清洗；回溯快照并非原站可执行页面。原件下载和清洗后的快照片段是不同用途。

关闭弹窗或页面、浏览器后台重启后，已持久化的队列继续恢复；未取得的页面资源可能无法补取。上传按文件恢复，不支持半个文件的字节 Range 续传。丢失确认时复用同一采集标识查询或重试，不应新建副本。自动重试用尽后需手动重试。只有服务器确认完成才显示“原文已保存”。原站后来离线不影响已归档的正文和成功保存的私有资源。

资料库包含 PDF、网页和仅链接条目。Reader 可切换原文、译文和段落双语，查看范围/警告、版本、目录及源节点快照，下载归档原件。新成果不会自动替换当前打开版本；选择切换后再阅读。阅读位置按文档 CAS 保存，设备冲突需明确选择从当前位置继续。

## BYOK、术语与自动翻译

在站点设置中保存自己的兼容模型地址、模型名和 Key。Key 在服务端加密存储，不进入采集包、HTML、任务快照或普通导出。扩展的网页翻译配置不会自动复制到站点。

自动翻译默认关闭。启用后，仅新保存且满足语言和配置条件的内容自动建任务；不会扫描并翻译历史资料。站点“添加链接”默认跟随此偏好，也可以为本次保存关闭自动翻译。中文原文默认无需翻译；无 Key、偏好关闭时先保存原文。混合/不确定/短文本需要明确选择源语言后手动开始。

Reader 的“翻译任务”允许选择段落、填写源语言、开始新一轮、取消或按原配置重试。开始模型翻译可能收费。任务绑定当时的模型配置和术语修订；换 Key 后旧任务暂停，需明确按当前配置开始新任务。修改术语不自动重译历史成果。取消后已确认的部分译文可能稍后发布，刷新成果即可查看；mock 回显只用于验证结构与生命周期，不代表翻译质量。

## 撤销、断开与重连

站点设备列表可撤销指定设备；撤销阻止新写入与迟到提交。扩展“断开连接”清除连接信息。重新生成配对码并连接同一站点、同一账号后，可恢复该账号队列；不同账号看不到、也不能投递旧账号的队列。普通站点退出会撤销本会话配对设备；已接受的服务器任务独立于浏览器运行。停用账号或重置身份会围栏旧任务。

遇到认证过期先在站点确认账号，再重新配对，不反复创建新收藏。上传失败可以查看队列警告并重试；“部分资源缺失”和“范围内不完整”各自保留真实原因。当前来源与验证边界见 [S3 验证记录](learning-site-s3-validation.md)。
