日期：2026-10-06。插件及 SDK 版本 0.3.0。此记录对应 M3 的个人术语维护与应用部分，不代表整个 M3 已完成。

## 已验证

- `npm run check` 通过：SDK 87、扩展 66，共 153 个单元测试；独立 tarball 消费测试 1 个；Chromium 扩展测试 36 个。日志保存在 `.superpowers/glossary-0.3.0/check.log`。
- 真实设置界面导入、重复导入、文件内部重复、搜索、手工修改、保存后重开、CSV 全表导入及 JSON 导出。
- 键按 `source.trim().toLowerCase()`＋领域归一化，最后写入覆盖；不同领域和导入中未提及的已有条目保留。非法文件不修改已配置词条。
- 未完成的手工词条或待确认文件导入会阻止保存，避免“已保存”与实际词表不一致。
- 标题、正文和公开 SDK 使用相同匹配与保护机制；最长完整词组、词边界、格式内部的独立词、Unicode 大小写折叠均有回归覆盖。
- `keep`、`translate`、`first-bilingual` 槽位缺失 / 重复阻止成功输出；本地快照还原不接受 Provider 修改。代码、公式和格式对象保持原有适配器契约。
- 一篇三块文档更新标题命中的一个词条后，两个无关块命中缓存，只有标题重新请求；添加未命中的词条后三块全部命中缓存。
- 含 100 个固定词条的长段落可以按预算拆分；每个请求只携带相关词条。跨分片的 prefer-source 词组提示继续跟随两侧片段，无关片段不携带该提示。
- 2,000 条非 ASCII 词表的 JSON 导出可再次导入；固定输出中的任一保留标记分隔符都被拒绝，避免拼接成页面适配器标记。
- 367 条 JSON 与 CSV 数据一致，重复整表合并后仍为 367 条；新增 harness、harness engineering、recursive self-improvement、RSI。
- SDK tarball 在仓库外安装、类型检查及纯 Node 运行，包含词表解析、合并和实际术语还原，不依赖 DOM 或 chrome API。
- 生产 ZIP 在未修改 manifest 的独立 Chromium 配置中加载，通过包内 JSON 导入、保存、重开、搜索及导出；导入前后保留 367 条。ZIP CRC 检查通过，无额外站点权限。日志保存在 `.superpowers/glossary-0.3.0/zip-smoke.log`。
- 保留原 M2 页面结构、X 动态页面、并发、缓存、停止及 worker 恢复回归。

独立只读代码审查发现的匹配回退、Unicode 折叠、术语密集段落预算、部分标记拼接和软偏好跨分片问题，均先复现再修复并加入测试；最终无剩余 Critical / Important / Minor 问题。

## 范围与限制

测试使用本地模拟 API，未读取本地密钥进行付费请求；结构和规则通过不等同于真实模型整体翻译质量通过。用户仍需在自己的 Edge / Chrome 与实际服务上验收。

词组匹配当前不跨原有强调 / 链接格式边界、代码或公式。领域由设置页手动选择，未实现自动领域识别、文档上下文分析、内置词表自动加载或动态词表。单段重试及选区译文回填仍待后续。

运行方式、文件维护和升级步骤见 [词表维护](glossary.md) 与 [安装指南](install-m2.md)。
