# 阅读助手使用说明（0.4.2）

PageLingo 的阅读助手在浏览器原生侧栏里，结合文章原文、选区和这篇文章的历史对话回答问题。可直接使用已配置的 Base URL、API Key 和 Model。初版没有搜索或工具调用。

## 更新与打开

如果当前加载的是 `apps/extension/dist/`，在 `edge://extensions` / `chrome://extensions` 重新加载 PageLingo，再刷新文章页并关闭、重新打开助手。使用 ZIP 的，先把 `pagelingo-0.4.2.zip` 解压内容覆盖到原加载目录，再重新加载和刷新；同一路径更新会保留现有设置。

- 在文章空白处右键，点击「PageLingo：打开阅读助手」。
- 或点击工具栏的 PageLingo 图标，再点击「打开阅读助手」。
- 侧栏的位置由浏览器控制；如果显示在左边，可在浏览器侧栏设置中改到右边。

普通 HTTP / HTTPS 网页可用；PDF、iframe 内选区和浏览器内部页面暂不支持。后续 PDF / LaTeX 阅读器会通过内容适配复用助手 SDK。

## 添加引用和提问

1. 在文章里选择文字或代码。
2. 右键「PageLingo：添加到对话」，选区会成为输入框上方的引用卡片。可连续添加多个引用。
3. 输入问题，例如「解释这段 NumPy 代码，给一个最小示例」。
4. 点击发送，或按 Enter。Shift + Enter 换行；Ctrl / ⌘ + Enter 仍可发送。输入法确认候选词的 Enter 不会触发发送。

**添加引用不会发送模型请求。** 引用和草稿在本地保存；用户发送问题后才请求模型。引用卡片默认显示选中的文字，最多三行，超出部分显示省略号；点击展开完整文字及来源，发送前可移除。预览截断只影响显示，模型请求和本地历史仍保留完整选区。代码保留原始缩进与换行，支持「定位原文」。在中文译文里选择内容时，可可靠映射的引用还会附上对应原文段落。

完整选区和你输入的问题放在最后一条用户消息中，一起请求模型；文章正文、引用来源和较早对话摘要单独作为背景提供。有本轮引用时，「解释一下这个东西」「这段代码」等问题优先指向选中文字；文章标题和章节名仅作为来源。例如只选择 `Reinforcement learning`，再问「这是什么意思？」，应解释强化学习，不将所在的整段引言当作选区。助手先解释所选概念或代码，再按需补充文章背景。明确指定其他对象或要求总结全文时，仍按问题本身处理。

未添加引用时，也能结合文章提问。助手读取原文、标题、章节、代码及可获得的公式文本；在中英对照或仅译文模式下，不会把扩展生成的译文当成文章原文。图片只提供文字说明；没有可提取内容时会提示。

## 上下文和记忆

- **自动选择上下文**：小文章提供全文；大文章按引用位置、邻近段落和问题关键词选择相关片段。
- **使用全文**：要求全文进入本次请求，超预算时明确报错。可以提高输入预算，或改为针对选区提问。
- **仅使用引用**：提供引用、问题、文章信息和对话历史，不添加正文块。

界面显示本次实际使用了全文还是片段、正文块数量和估算输入 Tokens。估算不是模型精确用量。显式引用和当前问题不会静默截断；过大时会要求缩小引用或调整预算。

历史较长时，会用模型整理较早的对话摘要，界面显示「正在整理较早的对话记忆」。摘要会产生额外 API 请求；全部原始消息仍保存在本地，最近的完整轮次继续提供给模型。失败或中断的回答不作为已完成历史。个人阅读偏好可在设置里填写，初版不自动推断跨文章的个人记忆。

## 历史、停止与重试

对话按文章 URL 保存，同一篇文章重新接入后恢复历史和草稿。常见跟踪参数及普通章节锚点不创建新对话；语义查询参数和 hash 路由会保留。只有发送过问题的文章进入历史列表。

默认保留 50 篇文章、64 MiB，可在设置中调整。超过上限优先清理较早使用的记录，保护正在生成的会话。历史支持查看、删除、清空及 JSON 导出；导出不包含 API 配置和密钥。对话历史与翻译缓存分别清理。

「停止生成」保留已收到的内容；「重试回答」沿用最后一个问题，不重复添加用户消息。侧栏关闭或刷新会中断生成，重新接入可重试；工具栏翻译任务仍按已有后台机制运行。

侧栏绑定打开它的标签页。切换到未打开助手的标签页时，浏览器隐藏侧栏；返回原标签页会恢复。可以在另一篇文章右键打开自己的助手，各标签页的文章与待发送引用分别保留。浏览器可能在切换时卸载侧栏页面，因此生成中的回答可能中断；返回后可重试。

同一标签页跳转到另一篇文章时，旧会话不自动成为新文章的上下文；在新文章右键打开助手，或点击「接入当前文章」。正在生成的回答始终保存到发起请求的那篇文章。历史里的文章更新后，旧引用保留快照，下一次提问使用新正文；已变化的引用位置可能无法直接定位。

## 设置与接口兼容

设置页新增「阅读助手」：

- 单独配置模型（留空时复用翻译 Model）、输入 / 输出预算、Temperature 和流式响应。
- 接口不支持 SSE 时，将「助手响应方式」改为「普通响应（兼容模式）」。
- Base URL、API Key、Token 参数、思考开关与模型上下文上限复用现有设置；对话不使用翻译的 JSON 输出协议。
- 超时或失败后由用户手动重试；对话请求不自动重试。

共享 SDK 的用法见 [assistant-core README](../packages/assistant-core/README.md)，设计见 [assistant-spec.md](assistant-spec.md)。
