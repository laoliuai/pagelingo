# M2-B / M2-C：预算、缓存与后台恢复

依据 `docs/web-spec.md`。用户已授权持续实现整个 M2，无需中间批准。M2-A 保留；M3 的术语与文档分析、PDF / LaTeX 适配器不进入本次实现。

## SDK

增强执行通过显式可靠性选项启用，保留旧 SDK 的严格、顺序调用语义。预算同时约束估算输入、预留输出和模型上下文；块数是第二上限。通用估算不是模型 tokenizer，也不是账单。长段按句子、词、Unicode 字符拆分，槽位不拆；跨分片格式使用原 token 和明确的续接边界，本地验证后合并。无法容纳的原子保护对象保留原文并报告失败。

首个未命中块优先。共享可取消队列按规范化 endpoint 限制两个并发。首次请求加两次重试为统一预算，网络、结构错误与后台恢复共用 attempt。429 尊重 Retry-After，加入抖动；鉴权和配置错误停止请求。批量截断缩小批次；最小分片仍截断则明确失败。部分成功只重试坏分片。成功块与失败块分开报告，失败原文不隐藏。

缓存 key 是规范化语义依赖的 SHA-256，包含原文、保护结构、语言、章节/标题、Provider 和实际生成配置、提示词/保护版本；不包含 API Key、随机 ID 或整篇正文 fingerprint。缓存只存带确定性槽位的文本，读取重新验证。完整块和拆分单元均可缓存。内容 fingerprint 覆盖整个有序文档；文档 URL 仅移除已知追踪参数和普通锚点。缓存、状态存储和调度使用可注入接口，SDK 无 chrome / DOM / IndexedDB 依赖。

Provider 支持非流式 JSON 与可选 SSE；设置首响应、读取空闲及总超时，限制响应体大小。统计实际 usage（若服务返回）、请求、重试、缓存块数、首段及总耗时。上游错误正文不进入用户消息。

## 扩展

扩展 origin IndexedDB（idb）包含 translations、documents、jobs。记录版本、访问时间和字节估算；默认缓存预算 64 MiB，结合实际配额、TTL 和 LRU。写入失败不阻止已验证译文显示，UI 告知持久化降级。提供分别清理译文、文档和全部缓存；清理缓存保留正在执行的任务检查点。

用户命令创建持久化会话授权。任务绑定 tab、主 frame、浏览器 documentId、页面会话、导航 key 和完整正文版本；持久化配置不含密钥。每次执行以 epoch 围栏保护写入；缓存与单元完成检查点在同一事务。恢复时重读可信设置并校验配置。worker 意外断开后内容脚本验证当前正文和导航，再重连并重放已完成结果；页面按块 ID 幂等处理。停止和正文变化持久化取消，并撤销未完成调度。未确认的页面不自动发请求。

活跃任务 Port 消息每 15 秒有界保活，任务结束关闭。Chrome alarms 作为重启后的回连提示；孤立任务暂停。整个浏览器重启或页面重载后，用户再次触发翻译才能恢复匹配的暂停任务；完成缓存始终可复用。网络不提供恰好一次付费保证。

## 验收与交付

SDK 单元测试：预算与长段保护、取消排队、统一尝试次数、部分成功、429/截断、缓存依赖/损坏及检查点重放。IndexedDB 测试使用 fake-indexeddb 执行真实事务，验证配额降级、清理、迁移和 epoch。Chromium 使用打包后的真实扩展，覆盖跨标签页并发、100 块改 3 块、缓存清理、停止、正文变化和实际终止 worker 后接续。

运行完整现有回归、独立 SDK tarball 消费，以及已配置的真实 API 页面翻译与第二次零请求缓存命中。交付生产 `dist` 和可解压安装的 ZIP，检查没有 `.env.local` 或密钥。提供 Chrome / Edge 安装与人工验收说明；浏览器原生 action / 权限弹窗和 Edge 由用户安装测试补充。
