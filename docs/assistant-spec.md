# 文档阅读助手第一版

状态：第一版实现完成，0.4.2 修复选区请求组织、回车发送与标签页侧栏绑定；验证结果见 [assistant-validation.md](assistant-validation.md)。日期：2026-10-07。用法见 [assistant.md](assistant.md)。

## 目标与范围

浏览器原生侧栏提供以当前文章为中心的连续对话。页面右键打开助手，选区右键「添加到对话」将文本或代码加入引用卡片；添加只更新草稿，用户补充问题后点击发送。首版工具列表为空，使用配置的 OpenAI-compatible 服务和 Pi 的对话运行层。

Enter 发送，Shift + Enter 换行，保留 Ctrl / ⌘ + Enter；输入法组合输入和候选词确认不触发发送。侧栏默认不在全窗口显示，用户打开时配置对应 tabId 的实例；切换到未打开助手的标签页隐藏侧栏，返回原标签页恢复。实例只接收其标签页的文章及引用投递。

引用卡片默认展示选中文字，最多三行，超出部分显示省略号；展开后查看完整内容和来源。标题或章节名不能替代选区预览；显示截断不影响请求、重试或持久化中的完整引用。

原生侧栏位置由浏览器设置决定，推荐设为右侧。已有翻译入口继续提供。对话不依赖文章已翻译；提取原文、章节、代码和可获得的公式文本，排除扩展译文。图片公式没有可提取文本时明确标示，不声称已理解图像。

## 上下文与通用引擎

`packages/assistant-core` 接收纯数据文档、选区引用、历史与模型预算，不依赖 Chrome、React 或 DOM。网页、未来 PDF / LaTeX 各自实现内容和存储适配。通用身份使用 documentKey，内容更新使用独立 revision。网页键保留语义查询参数，移除已知跟踪参数与普通章节锚点，保留 hash 路由。

用户明确引用与当前问题优先保留。短文章可提供全文；长文章按选区邻近关系、章节与本地关键词选择内容，界面显示实际覆盖范围。全文模式超过预算时要求缩小范围或增大预算，不默默用片段回答全文问题。长历史按预算生成摘要，保留原始记录；最近完整轮次和本次引用不可被静默截断。文章内容与引用作为资料处理，不成为系统指令。

文章背景与本轮问题使用不同消息：系统说明、完整历史、仅供参考的背景 JSON、最后一条用户消息。最后一条只含完整选区和问题，按原样保留缩进与换行；来源标题、段落 ID、原文对应段落及摘要放在背景消息。段落 ID 指向选区所在位置，不扩大选区。有引用时，含糊的「这个东西」「这段代码」等指代优先解析为本轮选区；先解释所选概念或代码，按需使用正文背景。用户明确指定其他对象或要求总结全文时遵循该请求，多个选区的对象不明确时可澄清。这一策略属于共享助手 SDK。

## 历史与运行

本地 IndexedDB 保存完整消息、引用快照、草稿和摘要；默认保留最近使用的 50 篇文章，64 MiB，总量和数量可配置。按最近使用清理，保护正在写入的记录及正在生成的会话；只有发送过消息的文章进入会话历史。提供查看、删除、清空、导出。清理翻译缓存不删除对话。

页面切换不混入其他文章历史。请求绑定发起时的文档与会话版本，回答保存到该文档。停止保留部分回答并标记中断，重试沿用原问题；刷新后的遗留生成记录恢复为中断。文章更新保留历史引用，后续请求采用新版本。

Pi 运行在受信任的侧栏扩展页面中。密钥从受信任设置读取，不传入页面内容脚本、不进入对话导出或构建。对话的输入预算、输出、温度、流式响应和模型覆盖单独配置；默认复用现有连接。Pi 特有类型不进入 SDK 公共接口。

## 验收

- 右键与面板入口可打开助手；添加一个或多个引用不产生 API 请求。
- 代码缩进和历史引用完整；重新打开同一文章恢复记录和草稿。
- 流式回答、停止、重试、错误处理不会重复消息或跨文章写入。
- 原文与已翻译网页的上下文一致，PDF / LaTeX 可通过纯数据使用相同 SDK。
- 预算、摘要、URL 身份、数量 / 容量淘汰、多窗口更新有必要的回归测试。
- 当前翻译、词表和独立 SDK 消费验证继续通过；产物是可加载的 Chrome / Edge 插件。
