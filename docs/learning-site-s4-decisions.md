# S4 实施裁定与影响

本记录按实施顺序列出执行中补齐的接口与验证决定。当前进度见[S4实施计划](superpowers/plans/2026-10-28-learning-site-s4.md)，本轮开发、验收与修正复核已完成，最终集成状态见验收文档。

1. 任务3先提供最小回收站入口，任务4再扩展恢复与永久清理。影响是路由定义提前，便于先验证删除后的权限行为。
2. S4未发布期间可继续扩展007–009，已发布001–006保持原样。影响是发布前需要统一迁移，旧写进程先停止。
3. 在仓库自己的隔离worktree实施，并先登记忽略规则。影响是增加一项可回退的工作区配置提交，主分支和宿主管理的旧工作区保留。
4. 四份原始S2大样本ZIP缺失时，使用已提交的固定S2/S3包验证，并明确真实大样本未重跑。影响是本轮真实大样本覆盖有限，不以新造包冒充原件。
5. DocumentOrganization响应增加lifecycleEpoch，PATCH不接受它。影响是新DTO多一个服务端字段，客户端能提交删除/恢复的预期epoch。
6. 已满足兼容目录分派、资产校验和Docker复制的既有代码接受无需修改的例外。影响是依靠实际兼容验证确认这些既有路径。
7. UUID标签在运行时按身份拒绝大小写不同的逻辑重复；portable Schema只承诺精确字符串uniqueItems。影响是shape-only校验后仍须执行共享语义校验。
8. 网络、模型、压缩、大对象读取及哈希移出事务；本地最终fstat/unlink等有界元信息操作保留在发布锁下。影响是短事务仍包含本地元信息I/O，远程存储适配时需要另核对其语义。
9. 任务3定义分域退休摘要与读取检查，任务4在删除业务行前持久保存最小收据。影响是UUID键规范化、旧不透明PDF键保留大小写，旧操作可被准确拒绝。
10. 整次维护共用500项业务变更和100次对象删除尝试预算。影响是大资料分批清理，处理中收据持续到实际内容清完。
11. 恢复校验覆盖全部历史上实际保留的原件、Reader、分片、资源和raw引用，不要求未完成孤立对象或可失效临时文件存在。影响是维护明确引用图，新功能须同步扩展。
12. 已有持久确认的插件载荷，可在启动或同用户重连时凭原始绑定证明整理；确认未知的载荷继续保留。影响是确认后无需手工清理，同时必须核对账号、设备代次和完整确认结果。
13. 稳定来源身份增加owner/provider摘要与数据库原始删除截止时间检查。影响是改名仓库或新论文URL中的旧入站操作也会被保守拒绝，删除后新操作仍可创建资料。
14. job增加可空GitHub/arXiv修订结果指针。影响是能展示复用修订的本次尝试，永久清理增加一项需计入预算的循环引用解除。
15. 图片采集增加内部受控downloadResource能力，保留原8MiB小响应和PDF协商语义。影响是测试transport增加显式方法，可兑现原16MiB图片上限。
16. 博客元信息使用新增显式提取接口，原snapshot-only入口保持原返回形状。影响是多一个有界元信息入口，同一次Readability结果提供标题/作者/时间。
17. 合法新翻译发布既有GitHub来源时，同事务选回与Reader匹配的已登记修订。影响是恢复后可继续翻译旧来源，歧义不靠最新行或同字节猜测；论文另用显式绑定。
18. 非法日历日期的M5 Minor安排在最终冻结前修正。影响是中间未发布代码暂存该已知边界，最终验收必须明确关闭。
19. 升级回归检查所需迁移身份和材料等值，不依赖总迁移数恒等于7。影响是增加008/009后测试仍验证原兼容责任，最终升级检查覆盖全部新迁移。
20. source-details增加可选readerVersionId，双参数校验真实配对；GitHub只允许实际关联或唯一source-only回退，论文只用显式绑定。影响是可准确查看历史来源，歧义需提示且不能伪造配对。
21. 在同一来源分类器补上arXiv/html入口。影响是插件可把该已批准来源交给站点适配器。
22. PDF本地客户端允许已有同源注册asset原件路由，保留URL限制。影响是历史论文原件可加载，需继续验证外源、任意路径和查询拒绝。
23. 离线输入补实际预览HTML与图片字节；生成器核对原件身份并重新清洗，隔离frame内使用已验证raster data:image。影响是调用者额外提供真实字节；缺少时明确不可用，IR不冒充归档快照。
24. 不要求未校验ZIP中的脚本自行证明可信；完整包由安装端可信目录重建并比对全部派生文件。影响是打开前的完整包校验承担替换文件拒绝责任。
25. 首个Web包只支持可重现的web-projector/1和defaultCaptureLimits；历史收紧配置或未知projector返回BUNDLE_UNSUPPORTED_SOURCE。影响是这些材料的网页完整包导出受限，原件与历史Reader继续保留，不从hash猜参数。
26. 临时导出在同一对象清理队列增加独立注册工作作用域。影响是009扩展队列约束与维护游标，永久清理收据保持单向完成；可失效ZIP不阻挡原件恢复。
27. 临时工作必须记录不可变写入任务/epoch/租约关联，排除仍有效写入，完成产物延后到过期清理。影响是额外记录与保守清理等待，需要中断/迟到发布回归。
28. 私有临时目录按固定深度和条目上限清理，内部文件删除尝试共用100预算。影响是清理可能分批，异常条目或符号链接保留明确失败与重试证据。
29. 冻结检查后的窄测试修订只复验受影响范围，原始广泛失败和每次快照均保留。影响是专项通过不宣称整套重跑，最终任务仍执行已批准的全量验收。
30. 旧测试重复使用历史截图路径：先发现任务6一张，后确认任务6另十张及任务5七个路径的出处缺口。影响是这18个路径的原始PNG字节无法独立核实；已保留所见字节、时间、哈希及追加更正，旧日志/trace作为独立证据保留，后续截图使用独立输出，不以新图冒充原图。
31. 已批准约束要求保留日志和真实失败证据，因此保留本计划ignored证据目录。影响是占用本地磁盘；公开验收和裁定进入仓库文档，原始证据不会因技能收尾建议被删除。

32. 最终服务检查确认旧迁移总数断言和paper/PDF拒绝断言已过时后，改验迁移身份和合法论文原件正向行为，同时保留跨类型/未配对拒绝。影响是窄修测试含义，原始399/401记录与修正结果分开保存，最终验收仍需运行。

33. 旧链接测试改为先确认原未知操作的重试，再显式开始新操作；模型调用断言改为本次操作前后差值。影响是保留原UUID/输入的恢复语义，并只衡量被验收操作的调用，原有原件、权限、布局和被动写入断言继续执行。

34. 退出快照回归需等退出成功与/login导航，再释放挂起资源并断言Blob/iframe归零。影响是验收已完成的退出边界；原始失败、未改代码的单项通过与同步修正后的结果分开保存，不用全局撤销掩盖所有权问题。

35. 原始执行报告、哈希快照和日志留在ignored工作目录；精选截图复制到正常文档目录。影响是修正一次本地未推送提交的文件归属，原始证据保留，公开文档仅包含精选材料及最终验收摘要。

36. 已完成导出的读取按当前会话、账号、资料权限和期限授权，不比较创建时的凭据版本；生成和发布仍校验原授权与epoch。影响是改密或恢复后，同一用户可继续读取仍保留的完成产物，旧会话与失效资料继续被拒绝。

37. 离线浏览器诊断只可将确切的已知隔离预览blocked-script提示归为预期，其余console/page错误失败。影响是保留原始诊断和无脚本、零payload、零出站断言，不用宽泛SecurityError白名单掩盖行为异常。

38. 完整S3→S4验收要求声明中至少包含一个经实际验证的已发布PDF包，缺少时在输出和服务创建前拒绝。影响是自定义验收声明也需明确升级基线，避免空基线或调用方标签冒充旧数据升级验证。

39. 开发验收中加载状态截图不能作为来源界面证据；补齐真实用户和页面就绪条件后，独立执行后续截图。影响是保留原图及其限制，明确测试框架的窄修订和各阶段冻结身份，不重跑不受影响的产品检查。

40. 最终审查边界：真实BYOK语义、费用与模型质量。接受S5验证边界；S4只证明调度/权限与mock零模型路径。 影响是仍需用真实Key和代表性材料单独评估质量与费用。

41. 最终审查边界：X/知乎/公众号登录态采集质量。接受S5真实会话验证边界；S4代码继续受采集预算与私有归属约束。 影响是真实页面兼容或登录态差异可能仍需修正。

42. 最终审查边界：真实arXiv PDF的解析、视觉与语义质量。接受source-only证据边界；合成论文目标绑定只证明关联，不能证明真实论文解析。 影响是尚未发现的论文布局/翻译问题需要本地处理链专项验证。

43. 最终审查边界：四份缺失S2大样本ZIP当前质量。接受环境不可得；已提交两份固定包只支持自身兼容结论，不伪造替代样本。 影响是原始大样本回归仍待输入可得后补验。

44. 最终审查边界：生产部署、停旧writer与备份恢复。接受S5操作边界；保留先停旧写进程再迁移的交接前提，开发验收不操作个人服务。 影响是上线前仍需真实停机/恢复演练。

45. 最终审查边界：旧二进制跨007–009继续写。接受明确不支持的混合版本运行方式；旧材料兼容不表示旧writer可持续运行。 影响是需要按部署协议同步切换API/worker，不能滚动混写。

46. 最终审查边界：最终live-public全应用运行和当前provider可用性。接受cached-public应用验证与实际匿名材料采集的区别；不声称应用实时抓取完成。 影响是实时链路/服务可用性仍需独立实网验证。

47. 最终审查边界：每个purge子阶段尤其document_purges自有对象分支的SIGKILL。接受本次只证明实际registered导出对象删后ACK前重启；持久清理实现仍按代码与相关回归评估。 影响是其他崩溃切面缺乏同等进程级证明，后续故障矩阵仍需扩展。

48. 最终审查边界：18张历史PNG的原始认证/恢复。接受不可独立认证，保留观察副本、errata及独立日志/trace；当前新图不冒充旧原件。 影响是无法用这些路径认证历史像素，不能消除该出处缺口。

49. 最终审查边界：四张当前精选图证明完整正文/PDF渲染。只接受各自限定证明范围；root已查看实际图片和身份，加载态图不作完成渲染证明。 影响是真实长正文和PDF视觉质量需其他行为证据或后续专项。

50. 最终审查边界：未知或收紧projector配置的Web导出。接受首格式只支持web-projector/1/defaultCaptureLimits，明确失败且保留原材料；此边界不豁免原附件漏导出I2。 影响是自定义历史配置当前不能完整导出，需要后续保存参数与支持策略。

51. 最终审查边界：Web ZIP重新导入站点。接受已批准S4仅导出/校验；PDF目标导入仍必须正常。 影响是Web包目前不能作为站点恢复导入口，需另做后续功能。

52. 最终审查边界：未经可信校验的篡改ZIP自证脚本可信。接受外部可信目录校验/重建的信任边界，不以包内脚本自证自身；正常导出仍必须验证完整闭包。 影响是独立取得的未知包需先经可信安装端验证，直接打开不能提供抗故意替换证明。

53. 最终审查边界：旧DEP0137与Task12孤立超时的追溯根因。接受旧精确根因未证明；迭代器修正、后续通过和旧失败各自保留。 影响是再次出现时需要新的堆栈/资源诊断，不能据旧推测排除泄漏。

54. 最终审查边界：单一最终HEAD全量全绿快照。接受按实际阶段报告原始广泛检查和后续定向修正，不将旧通过重标为新运行；五项修正必须有覆盖变更的实际验证。 影响是当前HEAD只享有实际执行的覆盖检查；未重跑的全套不宣称重跑。

55. 完整Web包增加可选、明确声明的惰性原件/来源附件闭包及不可变映射，保留现有source/IR/可信运行时校验和全部上限；协议canonical原manifest须匹配入站身份。历史原件先从已证明的所属源关系恢复，无法证明时明确不支持而非虚构出处。影响是增加合同/存储校验；缺少可证明历史映射的资料完整导出可能受限，服务器原件与Reader继续保留。

56. 完整导出同时保留来源创建采集，以及与其不同时、实际生成所选Reader的那次采集/候选译文，最多两组确定的不可变关联，不扫描全部历史或猜最新。原采集HTML/资源/64MiB/256文件上限逐组适用，完整包继续受原BundleLimits约束，可复用字节确实相同的登记路径；不另加跨两组共享64MiB限制。影响是增加有界原件验证和存储，须补来源/Reader配对、错误候选与总预算回归，采集和包的既有上限不提高。

57. 最终修正的两轮hash表仅覆盖1203份源码，没有测试前编译运行时hash表；依据保留构建日志、实际ZIP/进程/浏览器行为报告各自证明范围。805份编译产物补充快照明确为运行后交接记录，不能倒记为测试前证明。影响是这两轮精确运行时字节出处较弱，实际行为验证仍按原记录保留。

58. 专项复核复现合法长路径被新增前缀挤出上限，完整导出承诺尚未满足，不能把它停放后宣称完成。沿用同一实施者与专项审查席位补一项有界路径映射修正，作为已授权持续完成任务对通用技能末轮次数限制的明确例外；不另开整分支审查或无关全量检查。影响是增加一小轮覆盖验证与成本，例外和实际失败公开记录，不演变为无限审查。

59. 保留既有v1采集请求信封digest/重放语义；009新增字段只保存当时已经参与hash的授权请求，不重写旧digest或SDK语义。既有可选target UUID原始大小写仍可能影响旧请求digest，S4新的操作键和来源身份继续采用规范UUID身份。影响是只改target大小写的同key重试仍可能冲突，无法重建旧完整信封证明的历史资料完整导出可能受限，原件和Reader继续保留。
